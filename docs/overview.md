# 개요

> 목표: 텔레그램에서 원하는 상품을 자연어로 요청하면, 에이전트가 조건을 구체화하고 상품을 비교한 뒤 최종 후보를 제시한다. 사용자가 **구매 확정 버튼**을 누르면 로컬 구매 실행기가 쿠팡에서 주문과 결제를 수행하고 결과를 텔레그램으로 알려준다.

---

## 1. 한눈에 보는 결론

추천 구조는 다음과 같다.

```text
Telegram Bot
    ↓
대화형 Agent
    ↓ MCP
Shopping Service / Policy Engine
    ↓
HTTP Adapter + Playwright Adapter
    ↓
쿠팡
```

핵심 원칙:

1. **텔레그램은 대화와 승인 UI만 담당한다.**
2. **LLM은 구매 의도를 판단하지만, 결제를 직접 조작하지 않는다.**
3. **실제 구매는 고정된 서버 코드와 정책 엔진이 수행한다.**
4. **상품 검색·상세 조회는 HTTP 방식 우선, 주문·결제는 Playwright 중심으로 처리한다.**
5. **결제 후 결과가 불명확하면 재결제하지 않고 주문 내역부터 확인한다.**
6. **CAPTCHA, 재로그인, 추가 인증은 우회하지 않고 사용자 개입 상태로 전환한다.**

## 2. 사용자 경험

### 예시 대화

```text
사용자:
맥북에 쓸 무선 마우스 하나 사줘.
조용하고 휴대하기 좋고 5만 원 이하였으면 좋겠어.

봇:
몇 가지 확인할게요.
- 색상 선호가 있나요?
- 로켓배송 상품만 볼까요?
- 블루투스 연결이 필수인가요?

사용자:
검정색, 로켓배송, 블루투스 필수.

봇:
가장 적합한 후보입니다.

상품: 로지텍 ○○○
가격: 39,800원
색상: 그래파이트
연결: 블루투스
배송: 내일 도착 예정
수량: 1개
최종 예상 결제액: 39,800원

이 상품으로 구매할까요?

[구매 확정] [다른 후보] [취소]
```

사용자가 `[구매 확정]` 버튼을 누르면:

```text
봇:
최종 가격과 옵션을 다시 확인하고 있습니다.

봇:
구매가 완료되었습니다.
주문번호: 123456789
결제금액: 39,800원
도착 예정: 8월 6일
```

가격이나 옵션이 달라졌다면 자동 결제를 중단하고 다시 확인한다.

```text
가격이 변경되었습니다.

기존 가격: 39,800원
현재 가격: 41,300원

새 가격으로 구매할까요?

[41,300원에 구매] [취소]
```

## 3. 전체 아키텍처

```text
┌──────────────────────┐
│ Telegram             │
│ - 자연어 입력         │
│ - 상품 후보 표시      │
│ - 구매 확정 버튼      │
└──────────┬───────────┘
           │
┌──────────▼───────────┐
│ Telegram Bot Server  │
│ - 사용자 인증         │
│ - callback 처리       │
│ - 메시지 상태 관리    │
└──────────┬───────────┘
           │
┌──────────▼───────────┐
│ LLM Agent            │
│ - 요구사항 구조화     │
│ - 추가 질문 생성      │
│ - 후보 비교·설명      │
└──────────┬───────────┘
           │ MCP
┌──────────▼───────────┐
│ Shopping Service     │
│ - 상품 검색           │
│ - 주문 스냅샷 생성    │
│ - 구매 상태 관리      │
└──────────┬───────────┘
           │
┌──────────▼───────────┐
│ Policy Engine        │
│ - 금액·수량 한도      │
│ - 허용 카테고리       │
│ - 정기배송 차단       │
│ - 중복 결제 방지      │
└──────┬─────────┬─────┘
       │         │
┌──────▼─────┐ ┌─▼────────────────┐
│ HTTP       │ │ Playwright       │
│ Adapter    │ │ Adapter          │
│ 조회 우선  │ │ 주문·결제 중심   │
└──────┬─────┘ └─┬────────────────┘
       └──────┬───┘
              ▼
            쿠팡
```
