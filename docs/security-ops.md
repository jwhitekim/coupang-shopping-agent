# 보안 체크리스트 / 운영 및 장애 대응

## 16. 보안 체크리스트

### Telegram

- 허용된 `telegram_user_id`만 사용
- 개인 채팅 외 구매 명령 차단
- Bot Token을 저장소에 커밋하지 않음
- callback 데이터와 update ID 중복 검증
- 주문 확인 토큰을 짧게 유지
- `/stop`으로 구매 잠금

### 쿠팡 세션

- 전용 브라우저 프로필 사용
- 쿠키와 프로필 파일 권한 제한
- 클라우드나 Git에 업로드하지 않음
- 일반 로그에 쿠키, 헤더, 토큰 출력 금지
- 세션 만료 시 자동 로그인 우회 금지

### 결제

- 주문당·일일 금액 한도
- 허용 카테고리와 수량 제한
- 정기배송 및 상품권 차단
- 가격·상품·옵션·배송지 재검증
- 결제 버튼 한 번만 클릭
- 결과 불명확 시 주문내역 대조
- 고액 주문은 추가 확인 버튼 사용

### Agent

- 웹 페이지 텍스트를 신뢰할 수 없는 입력으로 취급
- 페이지 내 지시문이 에이전트 정책을 바꾸지 못하게 함
- MCP 입력을 스키마로 검증
- LLM의 자유 형식 브라우저 명령 금지
- 구매 도구는 서버의 저장된 주문 ID만 허용

## 17. 운영 및 장애 대응

### 추가 인증

```text
상태: USER_ACTION_REQUIRED
봇 메시지: 쿠팡에서 추가 인증이 필요합니다.
행동: 사용자가 headed 브라우저에서 직접 인증
결과: 세션 갱신 후 새 승인으로 재개
```

### 가격 변경

```text
상태: AWAITING_CONFIRMATION
행동: 변경된 가격과 주문 정보를 다시 보여줌
결과: 새 버튼으로 재승인
```

### 결제 결과 불명확

```text
상태: UNKNOWN
행동: 주문내역 대조
결과:
- 주문 발견 → COMPLETED
- 주문 미발견 → 자동 재결제 금지, 사용자에게 알림
```

### DOM 변경

```text
상태: FAILED
행동:
- 스크린샷과 비민감 로그 저장
- 선택자 또는 단계 수정
- 자동 재결제 금지
```
